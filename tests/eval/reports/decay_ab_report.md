# Decay A/B — does Ebbinghaus decay weighting change memory retrieval?

> 日期 2026-08-11 · 30 条标注 query · memory 路径 · 同一衰减状态下运行双臂
> **校准记录**：本报告跑在当前代码上——衰减公式已从 `S=1+(recall+1)·2` 调至 `S=1+(recall+1)·12`，并加 0.10 保留 floor（见下方「校准前后对比」）。

## 方法

生产 memory 读路径用 `similarity × decay_factor` 排序并写衰减状态。本 A/B 从**相同衰减状态**（快照/恢复保证）跑同一 30 条 query 两次：

- **decay on**（生产默认）：`weighted_score` 排序 + 写 recall 状态
- **decay off**（对照）：纯相似度排序，零衰减写入

新鲜 seed 语料下所有 factor≈1.0，A/B 无意义，故先施加一个**合成老化分布**（hot 1-10h / medium 12-39h / cold 48-120h，recall 0-15），让 decay_factor 真正区分行。分布是合成的——本测量隔离的是**公式对排序的影响**，不代表真实生产的衰减分布。

## 结果

| 指标 | decay on | decay off | Δ |
|------|---------|-----------|-----|
| recall@5 | 0.667 | 0.900 | -0.233 |
| mrr | 0.622 | 0.825 | -0.203 |
| ndcg@5 | 0.633 | 0.844 | -0.211 |
| 排序变化的 query 数 | 29/30 | — | — |

## 解读

- **校准后衰减仍显著改变排序**（29/30 条），但召回损失已大幅收窄：recall@5 0.667（decay off 0.900），约 10 条 query 的目标记忆被压出 top-5（校准前是 19 条）。
- **校准前后对比**（同一合成分布）：

| 参数 | recall@5 | MRR | 目标被压出 top-5 |
|------|---------|-----|-----------------|
| 旧公式 `S=1+(recall+1)·2` | 0.367 | 0.367 | 19/30 |
| 第一轮 `S=8 + floor 0.05` | 0.633 | 0.559 | 11/30 |
| **当前 `S=12 + floor 0.10`** | **0.667** | **0.622** | **≈10/30** |

  旧公式半衰期 ≈ 0.69·S 小时（未召回记忆约 2 小时减半），cold band 全部衰减到 ≈0，相关旧记忆整体沉底。12x 乘数把半衰期拉长到 9+ 小时，floor 0.10 保证完全衰减的记忆仍可凭高相似度浮起——衰减偏好保留（hot > medium > cold），但不把低频但相关的旧知识埋掉。
- **语义权衡**：decay on 仍低于 decay off（0.667 vs 0.900）是「过时沉底」的有意代价；调参没有消除差异，只是把代价从「埋掉一半旧记忆」降到「埋掉少数极冷记忆」。

## 边界

- 合成老化分布，非真实生产衰减状态；测量的是公式效应而非真实语料行为。
- 双臂起点一致（快照恢复），但 decay-on 自身随每次运行改变状态——跨天重跑数字可能漂移。
- 参数是基于本合成分布的调参，真实语料的「近期/高频=相关」假设可能不同，生产上宜收集真实衰减分布重新校准。
