# /build — 实现模式

读取设计文档，用 deepseek-v4-flash 高效执行实现。

## 当前任务

$ARGUMENTS

## 工作方式

1. **读取设计**：先查看 `docs/design/` 中相关设计文档
2. **委派执行**：将实现任务委派给 flash 子智能体，主会话缓存不受影响
3. **分批实现**：按设计文档中的实施步骤逐步实现
4. **测试验证**：每个步骤完成后运行对应测试

## 委派规则

- 写代码、修改文件 → 用 flash 子智能体执行
- 架构决策、设计变更 → 主会话（pro）自行处理
- 代码审查 → 主会话（pro）自行处理

## 注意

- 不要在实现阶段擅自修改设计，如有问题先讨论
- 实现完成后运行 `pytest` 确保测试通过
