# /design — 架构设计模式

使用 deepseek-v4-pro（当前模型）进行深度思考和架构设计。

## 当前任务

$ARGUMENTS

## 工作方式

1. **深入思考**：启用 extended thinking，全面分析问题的各个方面
2. **方案对比**：提供至少 2 个可行方案，对比优缺点
3. **设计输出**：将最终设计写入 `docs/design/` 目录
4. **影响分析**：说明对现有架构、API、数据模型的影响

## 输出要求

- 设计文档保存到 `docs/design/<feature-name>.md`
- 包含：问题描述、方案选择、架构图（文字描述）、接口定义、数据模型变更、实施步骤
- 用中文撰写，技术术语保持英文
